# PADDOX Next.js — Phase R2 Home Luxury Rebuild

This package upgrades the PADDOX Next.js foundation with a premium Home page shell.

## Replace files

Copy these files into your existing `paddox-frontend/paddox-next/` folder:

```txt
src/app/page.tsx
src/app/globals.css
src/components/home/home-experience.tsx
```

## Run locally

```bash
cd paddox-next
npm run dev
```

Open: http://localhost:3000

## Important

Do not run `npm audit fix --force`. Keep the fixed Next.js 14 package versions from R1.
